# LexiStudy v0.1.1 Stable Packaging Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze the existing LexiStudy v0.1.1 source and produce a verified Windows installer without changing business behavior.

**Architecture:** Update only release documentation and packaging metadata, copy the current source into a versioned backup, then build and package with the existing Electron/Vite pipeline. Verify the generated artifact, packaged resources, installer metadata, and launch behavior.

**Tech Stack:** Electron, React, TypeScript, Vite, electron-builder, npm.

## Global Constraints

- Do not modify learning algorithms, SQLite schema, vocabulary data, UI layout, or shortcut logic.
- Keep `vocabulary_final.json` unchanged.
- Preserve `Backup/v0.1.0-final`.
- Use version `0.1.1` and output `LexiStudy-Setup-0.1.1.exe` under `Release`.
