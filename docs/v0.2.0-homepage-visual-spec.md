# LexiStudy v0.2.0 首页视觉规范

> 用途：作为 HomePage 实现前的最终视觉依据。
>
> 范围：只调整首页表现层，不增加功能、不增加业务组件、不修改业务逻辑。

## 0. 实施边界

本规范基于 `docs/v0.2.0-homepage-redesign-plan.md`，只定义首页的视觉结构、空间、主题、层级、动效和窗口适配。

必须保持不变：

- `HomePage` 现有 props、回调、文案语义和状态判断。
- 开始学习、继续学习、再学一轮、选择词库和每日目标按钮的行为。
- `ProgressCard` 的百分比计算、数据来源和进度含义。
- SQLite、学习算法、学习队列、词库 JSON、IPC、路由和快捷键。
- 不新增独立业务组件，不新增业务状态，不新增数据字段。

允许改变：

- section 的展示顺序、包装 class 和网格关系。
- CSS token、主题颜色、间距、圆角、字号和图标表现。
- 纯展示性的可访问性属性和 focus-visible 样式。
- 不阻塞交互的进入动画、进度视觉过渡和窗口适配样式。

## 1. 首页新版信息架构

### 1.1 信息优先级

首页按以下优先级组织，不增加信息内容：

1. **今日行动**：页面标题、每日目标说明、开始/继续学习 CTA。
2. **学习上下文**：当前词库名称、词数、来源和选择词库入口。
3. **今日进度**：今日学习百分比、已学习数量和目标数量。
4. **目标控制**：35/50 个新词目标选择。
5. **摘要指标**：词库总数、今日已学、认识。
6. **学习提示**：每次只专注一个单词的辅助说明。

### 1.2 页面结构线索

```text
HomePage
└── page-stack home-page
    ├── home-hero
    │   ├── eyebrow + H1 + daily target description
    │   └── primary CTA
    ├── dictionary-context
    │   ├── current dictionary information
    │   └── secondary CTA
    ├── home-focus-grid
    │   ├── ProgressCard
    │   └── target-panel
    ├── home-metrics
    │   ├── metric-card: 词库总数
    │   ├── metric-card: 今日已学
    │   └── metric-card: 认识
    └── home-guidance
        └── info-panel
```

以上是现有页面区域的视觉分组，不代表创建新的业务组件或数据模型。

### 1.3 首屏规则

- `1180×760` 标准窗口：标题、主 CTA、当前词库、主进度和今日目标应尽量在首屏可见。
- `920×620` 紧凑窗口：标题、主 CTA、当前词库和主进度优先可见，目标面板自然位于其后并可滚动访问。
- 宽屏/全屏：不重复展示数据，不用空白填满页面；扩大主进度和目标区域的呼吸空间。

### 2.3 宽屏/全屏

- 左侧导航保持稳定宽度，内容区域使用剩余空间。
- 页面容器最大宽度建议 `1120px`，必要时可在 `1200px` 内扩展。
- `home-focus-grid` 使用额外宽度增加左右留白和卡片呼吸空间，不无限放大字体或环形进度。
- 指标卡保持三列，不扩展为虚假的新指标。
- 页面垂直高度增加时，区域间距可以使用 `clamp()` 增长，但内容优先级不变。

## 3. 深色模式视觉方案

### 3.1 页面背景

- 根背景使用 `--color-bg: #0B111B`。
- 内容区可使用 `--color-bg-soft: #101925` 和极低对比的蓝色径向光晕。
- 不使用纯黑大面积背景，不使用白色边缘或白色卡片。

### 3.2 区域表面

- `dictionary-context` 和 `metric-card` 使用 `--color-surface`。
- `ProgressCard` 使用 `--color-surface-elevated`，成为首页最强内容表面。
- `target-panel` 使用 `--color-surface`，通过标题和控制组区分，不与主进度卡抢焦点。
- `home-guidance` 使用低对比表面或背景分隔，不使用高亮边框。

### 3.3 颜色语义

- 主 CTA：`--color-brand` / `--color-brand-strong`。
- active 目标按钮和进度环：品牌蓝。
- 已完成、认识、满进度：`--color-success`，黄绿色只承担完成语义。
- 辅助文字：`--color-text-muted`。
- 次要说明：`--color-text-subtle`。
- 错误或保存失败：`--color-danger`，但首页不主动展示错误色。

### 3.4 深色层级

页面由“背景 → 普通面板 → 主进度面板 → active 控件”四层构成。层级主要由表面明度、蓝色倾向和空间区隔建立，不依赖大量 1px 灰色边框或厚重阴影。

## 4. 浅色模式视觉方案

### 4.1 页面背景和卡片

- 根背景使用 `--color-bg: #F4F8FC`。
- 内容区使用 `--color-bg-soft: #EAF2F9`。
- 普通面板使用 `--color-surface: #FFFFFF`。
- 主进度卡使用 `--color-surface-elevated: #F8FBFF`，可通过浅蓝色内发光或柔和阴影突出。
- 不使用纯黑文字、纯蓝大面积填充或高对比粗边框。

### 4.2 控件与状态

- CTA 和 active 控件使用浅色主题的品牌蓝值，确保文字和背景达到可读对比度。
- 浅色主题实心 CTA 使用白色文字配 `--color-brand` 或 `--color-brand-strong`；深色文字只用于浅色 focus 表面或低填充 secondary 控件。
- 完成状态使用浅色主题对应的深橄榄绿/深青绿。
- 词库来源标签、目标选中状态和进度环使用统一语义映射。
- 浅色主题不得改变组件尺寸、顺序、信息内容和操作行为。

## 5. 组件层级关系

### 5.1 页面级

```text
Page background
└── AppShell content area
    └── home-page container
        ├── Home hero: primary attention
        ├── Dictionary context: secondary context
        ├── Home focus grid: progress + target
        ├── Metrics: tertiary summary
        └── Guidance: lowest emphasis
```

### 5.2 内容级

每个区域内部遵循：

```text
eyebrow / section label
└── title or value
    └── description / status
        └── control, when applicable
```

- 标题不超过一个主要层级。
- 说明文字不与数值争夺对比度。
- 控件与其说明保持同一视觉分组，避免漂浮在面板边缘。

### 5.3 主次关系

- Hero CTA 是页面唯一的 primary action。
- “选择词库”是 secondary action。
- 35/50 是 segmented choice，不使用两个同等级 primary button。
- 指标卡只展示摘要，不承担跳转或新增交互。
- 学习提示不使用可点击样式。

## 6. 卡片布局规范

### 6.1 通用卡片

- 普通卡片圆角建议 `16px`，主进度卡建议 `20px`。
- 普通内边距建议 `20–24px`，主进度卡建议 `28–40px`，由窗口高度使用 `clamp()` 调整。
- 卡片内部使用 `8px` 基础空间系统，标题、说明、数字和控件之间保持明确节奏。
- 卡片宽度允许收缩，子项使用 `min-width: 0`，长词库名称允许换行或省略。
- 使用语义背景和低对比边界，不为每张卡片创建独立颜色。

### 6.2 主进度卡

- 左侧显示“词库学习进度”、百分比和今日学习说明。
- 右侧显示环形进度和已学习数量。
- 宽窗口比例约 `1.25fr 1fr`；紧凑窗口改为单列或保持两块紧凑对齐，不能让数字和圆环重叠。
- 百分比字号使用 `40–56px`，不固定为 `68px`。
- 环形进度不使用新的数据，只映射现有百分比。

### 6.3 目标面板

- 标题区和 35/50 控制区横向排列；紧凑窗口纵向排列。
- 目标按钮具有默认、hover、selected、focus-visible 和 disabled 状态。
- selected 状态使用品牌蓝背景/边界，完成语义不与目标选择混用。
- 两个目标按钮宽度接近，保持稳定的视觉选择关系。

### 6.4 指标卡

- 宽窗口三列，使用 `minmax(0, 1fr)`。
- 紧凑窗口根据可用宽度降为两列或一列。
- 每张卡只包含 label、主数值和辅助说明三层。
- 主数值使用统一数字字重和行高，不能因为数据位数变化导致卡片高度跳动。

## 7. 按钮层级规范

### 7.1 Primary CTA

用于“开始学习”“继续学习”“再学一轮”。

- 品牌蓝背景，深色文字或符合对比度要求的文字。
- 圆角约 `10–12px`，高度建议 `40–44px`。
- 右侧使用 `14–16px` 轻量箭头图标。
- hover 只做轻微表面提升，active 使用轻微缩放，focus-visible 使用清晰焦点环。
- 仍然使用现有 `Link`、路由和 `onStartSession` 行为。

### 7.2 Secondary action

用于“选择词库”。

- 使用透明/低对比表面、品牌边界或文字按钮样式。
- 不与 primary CTA 使用相同填充强度。
- 保留较大的点击区域和文字可读性。
- 仍然导航到现有词库管理页面。

### 7.3 Segmented choice

用于每日目标 35/50。

- 两个选项属于同一控制组，外观相近。
- selected 通过品牌蓝、浅色背景和焦点状态表达。
- 不添加新的目标选项，不把它们设计成两个独立 CTA。

### 7.4 Disabled 和反馈

- disabled 降低透明度并显示不可操作光标，不改变布局尺寸。
- 保存中状态使用现有回调状态，不添加新的保存流程。
- 首页不使用持续闪烁、弹窗或声音反馈。

## 8. 页面进入动画规范

### 8.1 进入顺序

首页首次从加载状态进入后，按视觉层级轻微错峰：

1. `home-hero`。
2. `dictionary-context`。
3. `home-focus-grid`。
4. `home-metrics` 和 `home-guidance`。

动画只影响展示，不延迟 CTA 可用时间，不改变数据加载和路由时机。

### 8.2 动效参数

- 初始状态：轻微 `translateY` 和 `opacity` 变化，不使用大幅位移或模糊遮挡。
- 单组动画：`160–240ms`。
- 错峰间隔：建议 `30–50ms`，总进入时间不超过 `400ms`。
- 曲线：`cubic-bezier(0.32, 0.72, 0, 1)` 或同等级自然减速曲线。
- 只动画 `transform` 和 `opacity`，不动画 `width`、`height`、`top`、`left`。

### 8.3 减少动效

`prefers-reduced-motion: reduce` 时：

- 取消错峰、位移、模糊和高光。
- 使用静态渲染状态。
- 保留颜色、边界和文字反馈。

### 8.4 进度变化

- 目标切换后，进度卡可对进度环和数字做短暂过渡。
- 进度数据必须立即正确，动画不能参与 SQLite 保存、学习算法或答题流程。
- 今日完成状态只使用一次轻微成功色变化，不添加游戏化奖励。

## 9. 不同窗口尺寸适配规则

### 9.1 `920×620` 紧凑窗口

- 侧栏使用紧凑宽度，但导航文字和图标保持可读。
- Hero 标题和 CTA 纵向排列。
- 当前词库信息允许名称换行，选择词库按钮保持完整。
- 主进度卡优先显示，目标面板排在其后。
- 指标卡降为两列或一列，禁止横向溢出。
- 页面允许纵向滚动，滚动区域背景与根背景一致。

### 9.2 `1180×760` 标准窗口

- 使用标准页面间距和 `home-focus-grid` 两列布局。
- Hero、当前词库、主进度和目标面板构成清晰首屏路径。
- 指标卡三列显示，学习提示位于页面下方。
- 进度百分比和环形进度保持视觉平衡，不出现空洞或拥挤。

### 9.3 `≥ 1280px` 宽窗口

- 内容容器可以扩展到 `1120–1200px`，不继续放大核心字号。
- 主进度卡和目标面板增加内部留白，不创建新的信息块。
- 指标卡保持三列，卡片内容垂直对齐。
- Hero 和上下文区域保持明确起点，不因扩展而分散。

### 9.4 全屏和高窗口

- 使用增加垂直间距和卡片内留白的方式利用空间。
- 页面背景、侧栏和内容区无白边、白闪和断层。
- 主进度卡不无限增高，指标和提示不被推到不可访问的位置。
- 不通过新增 Dashboard、图表或统计组件填充空间。

### 9.5 字体缩放

- `--font-scale: 1`：100%，标准默认。
- `--font-scale: 1.25`：125%，舒适阅读，允许卡片自然增高。
- `--font-scale: 1.5`：150%，用于较大显示比例或较远观看距离。
- `--font-scale: 1.75`：175%，最大可读性优先，允许页面自然增高。
- 四档下均需验证标题、词库名称、按钮、进度数字和指标说明不重叠。

## 10. 最终实现验收

- 首页只保留现有信息和操作，不增加功能或业务组件。
- 首屏能明确回答：今天学什么、当前进度是多少、点击哪里继续。
- 深色模式视觉与品牌蓝/完成绿语义一致，浅色模式可读且不反转业务含义。
- Home hero、词库上下文、主进度、目标控制、指标和提示的层级稳定。
- 进入动画短、轻、可关闭，不阻塞用户操作。
- `920×620`、`1180×760`、宽屏和全屏状态无横向溢出、白边、白闪和内容断层。
- SQLite、学习算法、词库 JSON、IPC、路由和快捷键行为保持不变。
