## Major Changes

- Completed the StudyPage UI implementation and Review 4 visual freeze.
- Froze and implemented Word Card Visual Design V2.2.
- Introduced Theme System V2 with a Single Accent per theme:
  - Dark: Black + Green.
  - Light: White + Blue.
- Added Appearance infrastructure with `AppearanceManager`, Theme Registry, and `AppearanceProvider`.
- Added Settings > Appearance > Theme with Light and Dark options.
- Persisted Theme selection through `localStorage["lexistudy.appearance.theme"]`.
- Reserved `system` in the Theme architecture without exposing or persisting it.

## Theme and UI Corrections

- Home primary learning progress follows Theme Accent.
- Sidebar current progress follows Theme Accent.
- Statistics Today Target, Total Study Count, Total Accuracy, and Mastery Distribution follow Theme Accent.
- Explicit Success, Known, Completion, and Success Feedback continue to use Success Green.
- Danger and Error semantics continue to use Red.

## Today Learning Metric

- Home and Statistics now use the same date-scoped `todayCompleted` source.
- Home no longer treats the cross-date `sessionIndex` queue position as today’s completed-learning count.
- Daily target counts remain synchronized between Home and Statistics.

## Percentage Precision

- Home and Statistics share `calculateRoundedPercentage()`.
- Daily progress is displayed as an integer using normal rounding.
- Example: `1 / 35` displays as `3%`.
- Zero targets and non-finite inputs safely display `0%`.
